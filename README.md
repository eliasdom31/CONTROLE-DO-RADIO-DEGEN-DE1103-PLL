# CONTROLE-DO-RADIO-DEGEN-DE1103-PLL
Projetos dos modulos de controle dos radio DEGEN DE1103 PLL
Baseado em codigo CC+ na plataforma IDE
Baseado em Microcontroladores ATMEGA328 e ESP32
Controlando o CI  LC72137 da SANYO via protocolo CCB
São 3 modelos distintos:
1 - Display OLED 0,91 / SSD1306 / 128x64 com Microcontrolador Arduino Nano
2[DE1103.pdf](https://github.com/user-attachments/files/31148326/DE1103.pdf)
 - Display LCD NOKIA 5116 / com Microcontrolador Arduino Mini-Pro
3 - Display TTF ST7735 / com Microcontrolador ESP32
